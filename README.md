# kalima-content — переводы приложения «114 · Калима»

Этот репозиторий приложение читает напрямую (raw-файлы GitHub).
В само приложение встроен только **арабский текст Корана**; всё остальное — здесь.

```
manifest.json          версии пакетов (приложение сверяет их при запуске)
ui/<язык>.json         язык интерфейса: все надписи + названия 114 сур
                       ar, ru, en, tr, kk, ky
words/<язык>/NNN.json  перевод слов суры NNN: [краткий, подробный] по аятам
                       ru, en, tr, kk, ky
words/ar/NNN.json      арабское толкование автора (Башир Ахмад Сулейман Юнус)
                       — нужно при любом языке
tools/build_words.py   пересборка words/ и manifest.json из файлов surah_XXX.dart
```

## Как это работает в приложении
1. Первый запуск: приложение без надписей (кроме экрана выбора языка и входа).
   Пользователь выбирает язык → скачивается `ui/<язык>.json` (≈15 КБ).
2. Открыта сура → скачиваются `words/<язык>/NNN.json` и `words/ar/NNN.json`
   (по одной суре, с кэшем на телефоне).
3. Настройки → «Офлайн-переводы» → «Скачать»: все 114 сур языка + толкование
   (рус. ≈ 11 МБ + араб. ≈ 8 МБ), дальше всё работает без интернета.
4. Арабский язык интерфейса: только толкование автора (`words/ar`).

## Формат файлов
`words/ru/001.json`
```json
{"s":1,"l":"ru","a":[[["Во имя","Предлог «би» …"],["Аллаха","Имя …"]], …]}
```
`a` — аяты по порядку, внутри — слова по порядку (как в Коране), у каждого
`[краткий перевод, подробный перевод]`. У `words/ar` у каждого слова одна строка.

`ui/ru.json`
```json
{"v":1,"lang":"ru","groups":{"app":{…},"reader":{…},…},"surahs":{"1":["Аль-Фатиха","Открывающая"],…}}
```

## Как обновить переводы
**Надписи интерфейса** — правьте `ui/<язык>.json` прямо в GitHub, затем
запустите `python3 tools/build_words.py <папка_с_сурами>` (он пересчитает
`manifest.json`) или вручную увеличьте `"v"` у этого языка в `manifest.json`.

**Переводы слов** — исправьте файлы `surah_XXX.dart`, затем:
```
python3 tools/build_words.py /путь/к/Quran_114 --app /путь/к/flutter-проекту
```
Скрипт перезапишет изменившиеся файлы и поднимет версии в `manifest.json`.
Закоммитьте и отправьте в GitHub. При следующем запуске приложения:
кэш устаревших переводов сбросится сам, а у тех, кто скачал переводы для
офлайна, в настройках появится кнопка «Обновить».

Важно: **не меняйте число и порядок слов** в аятах — оно совпадает с
арабским текстом, встроенным в приложение (`assets/quran/quran.json`).
Если меняется арабский текст, нужно выпустить и новую версию приложения
(флаг `--app`).
